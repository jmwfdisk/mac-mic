# Mac Mic

Mac 마이크로 들어오는 주변 소리를 핸드폰 웹 브라우저에서 실시간으로 듣는 단일 HTML 페이지입니다.
설치할 앱도, 서버도 없습니다. GitHub Pages에 올려두면 됩니다.

## 사용법

1. **Mac**: 페이지를 Chrome/Safari로 열고 **소리 보내기 시작** → 마이크 권한 허용
2. **핸드폰**: Mac 화면의 QR을 찍거나 링크를 열고 **듣기 시작**

- 주소(코드)는 Mac 브라우저에 저장되므로, 핸드폰에서 한 번 열어 북마크해 두면 다음에도 같은 링크로 들을 수 있습니다.
- 링크가 유출됐다면 Mac에서 **새 주소 만들기**를 누르세요. 기존 링크는 바로 끊깁니다.
- Mac 탭을 닫거나 Mac이 잠들면 전송이 멈춥니다(시스템 설정 → 에너지 → "디스플레이가 꺼져 있을 때 자동으로 잠자지 않게 하기").

## 동작 방식

- 소리는 **WebRTC로 Mac → 핸드폰에 직접(P2P) 암호화 전송**됩니다(DTLS-SRTP).
- 두 기기가 서로를 찾는 신호 교환에만 무료 공개 서버 [PeerJS Cloud](https://peerjs.com)를 씁니다. 오디오는 거치지 않습니다.
- 코드는 12자리 무작위 문자열이며, 링크를 아는 사람은 누구나 들을 수 있습니다. 링크를 공유하지 마세요.

## 제약

- TURN 중계 서버가 없어서, 일부 통신사 LTE/5G나 회사 방화벽처럼 직접 연결이 막힌 네트워크에서는 연결이 안 될 수 있습니다. 같은 Wi-Fi에서는 항상 됩니다.
- iPhone은 화면이 잠기면 소리가 멈출 수 있습니다("듣는 동안 화면 켜두기"가 기본으로 켜져 있음).
- 마이크 사용은 HTTPS(또는 localhost)에서만 됩니다. GitHub Pages는 HTTPS입니다.

## 주의

다른 사람의 대화를 동의 없이 듣거나 녹음하는 것은 「통신비밀보호법」 위반이 될 수 있습니다. 본인 공간을 확인하는 용도로만 쓰세요.

```bash
python3 -m http.server 8000   # http://localhost:8000
```
